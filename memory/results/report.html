openclaw — 조준이 정확한 5섹션

Decisions/TODO/제약/미결 요청/식별자 고정 구조가 "미래 세션에 필요한 것"에 정조준. 7.4배 작은 요약으로 회상 1위. 유일하게 "대화의 주 언어로 작성"을 명시해 한국어 요약 6/6.

claude-code — 요약이 아니라 인덱스

사용자 메시지 전수 나열 + verbatim 인용 강제로 산출물이 원본의 57%. 정확도는 2위지만 토큰 효율 꼴찌. 단 실제 하네스에선 transcriptPath로 원본 복구가 전제된 설계라 실전은 이보다 유리.

codex — 426자 프롬프트의 가성비

grok — 언어가 널뛴다
